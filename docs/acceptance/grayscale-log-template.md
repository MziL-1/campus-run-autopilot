## 每日纪律（每天提交前自检）

1. 每日恰好 ≤1 次提交（提交前只读回查"最近记录"确认无当日记录）；
2. 提交保持在校时段内（本校 10:00–22:00，`runRuleModel` 窗口）；
3. 提交结果须工具侧 `valid=true`；
4. 次日（≥1 小时后、当日提交前）在官方 App 回查前一日记录；
5. 任何风控异常立即记入"风控观察"列并停止后续灰度、回报。

### 填写口径

- **提交结果**：`时刻 · 距离 · 工具侧回查（id=… valid=true）`，或 `失败/跳过 + 原因`（跳过/失败 = 当日不满足"提交成功"，连续计数中断）。
- **回查结果**：`官方 App 回查：日期 · 距离 · 有效性原文（有效/达标 or 异常）`；官方侧不可用时先记工具侧并标注待补。
- **风控观察**：无异常写 `无`；有则原文记录——封禁 / 记录异常 / 黑名单提示 / 10121 单设备登录保护 / 频繁验证码或滑块 / 成绩被清除等。另观察：服务端若开始拒收 2030 m（>dayGoal 2000 m）记录，记入本列并当日起将目标收敛为 ≤2000 m（见 `phase1a.md` §2 观察项）。
